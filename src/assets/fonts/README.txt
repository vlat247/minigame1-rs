Pixelify Sans, version 1.000

Unmodified full variable TrueType font from the official Google Fonts repository:
https://github.com/google/fonts/blob/main/ofl/pixelifysans/PixelifySans%5Bwght%5D.ttf
The upstream filename is PixelifySans[wght].ttf; renamed locally for simple URLs.
License source: https://github.com/google/fonts/blob/main/ofl/pixelifysans/OFL.txt
License: SIL Open Font License 1.1; see the accompanying unmodified OFL.txt.

Weight axis: 400 through 700. Font size: 79,160 bytes. Glyph count: 576.
SHA-256: 9ba86cd010a4de309d263ceff8e8044092c9db7efda869620cb9ff1c4389e8a5
Upstream Git blob: 2d7eb388ee499fbcf3e992723ec409c095640104

Digits, plus/minus (U+00B1), Unicode minus (U+2212), Latin, and most Cyrillic
are included. Uppercase Cyrillic O (U+041E) and Pe (U+041F) are absent in the
upstream font and use the application's normal font fallback.
